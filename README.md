# 🌱 EcoLoop

**Industrial Emission Intelligence & Circular Alternative Recommender**

EcoLoop is a smart sustainability platform that helps industries calculate carbon emissions, detect emission hotspots, and receive AI-inspired circular economy recommendations through an interactive dashboard.

## 🚀 Features

- 📊 Dashboard with emission analytics
- 🏭 Factory data management
- 🌍 Carbon emission analysis
- 🔥 Hotspot detection
- ♻️ Circular alternative recommendations
- 📈 What-If simulation for emission reduction

## 🛠 Tech Stack

- React 18
- Vite
- React Router
- Recharts
- Lucide React

## 📁 Project Structure

src/
 ├── pages/
 ├── components/

 └── services/
